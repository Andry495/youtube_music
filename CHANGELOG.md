# Changelog

## 1.5.0 — 2026-10-07

- **Офлайн-first:** воспроизведение с диска (`ytvcache` / локальный m3u8) без ожидания URL; URL только для докачки кеша
- Стабильные ключи сегментов (itag+gosq), дедуп CDN-дублей при докачке и перед офлайн-плейлистом
- Полнота трека по длительности каталога: `N/M` сегментов, докачка **от позиции вперёд**
- Prefetch окна: сначала текущий (запас ~90 с вперёд), затем следующие треки по одному
- Переход на следующий трек только после реального конца трека (не конца короткого отрывка)
- UI прогресса: слой **кеша на диске** (до какого момента скачано) + слой **RAM-буфера** + позиция
- Статусы busy/докачки понятнее; буфер ExoPlayer ≠ объём на диске

## 1.4.0 — 2026-10-05

- DPI — **опциональный** модуль: по умолчанию выкл., не конкурирует с VPN телефона (StrongSwan и т.п.)
- Кэш: политики окна / LRU / окно+LRU; порядок prefetch; статистика в UI
- Скип трека **не** чистит весь кэш: `retainOnly` по окну, затем докачка дырок (в т.ч. с диска)
- Стабильность: OOM на длинных HLS (рекурсия `hls_playlist`), свёртывание UI (MediaController только с main), случайный next при BUFFERING
- `largeHeap`, мягкий LoadControl; ключи кэша привязаны к track id

## 1.3.2 — 2026-10-02

- DPI: локальный TUN (VpnService → hev → ByeDPI) только для этого приложения; SOCKS — запасной путь
- Исправлен `--protect-path` (argv живёт до остановки прокси)
- Встроенные пресеты + автоподбор на устройстве; удалённый VPN-сервер не нужен
- На части сетей TSPU пресет может не найтись — внешний VPN/Zapret по желанию пользователя

## 1.3.1 — 2026-10-01

- DPI переведён на локальный SOCKS ByeDPI (без системного VPN/TUN) — трафик приложения реально идёт через обход
- Тумблер в настройках больше не запрашивает VPN-разрешение

## 1.3.0 — 2026-10-01

- Встроенный локальный DPI (ByeDPI + hev-socks5-tunnel): только трафик приложения, без удалённого VPN
- Тумблер в настройках (шестерёнка); системное разрешение VPN; уведомление при активном обходе
- NOTICE: лицензии ByeDPI / hev-socks5-tunnel (MIT)

## 1.2.0 — 2026-10-01

- Умный дисковый кэш: prefetch **3** следующих трека, лимит **64–256 МБ** (5% свободного места)
- До ~10 МБ на префетч-трек; при смене трека/плейлиста удаляются ключи вне окна current+3
- Документация: почему Zapret нельзя встроить в APK; как пользоваться внешним DPI-обходом без классического VPN

## 1.1.1 — 2026-10-01

- Исправлено падение при старте: ExoPlayer больше не вызывается с `ConnectivityThread` (сетевой callback → main)

## 1.1.0 — 2026-10-01

- Возобновление потока при потере/смене сети (Wi‑Fi ↔ мобильный интернет): сброс OkHttp-пула, новый URL, seek на ту же позицию
- Сохранение очереди, текущего трека и позиции (DataStore); восстановление после закрытия приложения
- Play/Pause больше не сбрасывает трек на начало
- `ACCESS_NETWORK_STATE` для отслеживания сети
