# Changelog

## 1.3.1 — 2026-10-01

- DPI переведён на локальный SOCKS ByeDPI (без системного VPN/TUN) — трафик приложения реально идёт через обход
- Тумблер в настройках больше не запрашивает VPN-разрешение

## 1.3.0 — 2026-10-01

- Встроенный локальный DPI (ByeDPI + hev-socks5-tunnel): только трафик приложения, без удалённого VPN
- Тумблер в настройках (шестерёнка); системное разрешение VPN; уведомление при активном обходе
- NOTICE: лицензии ByeDPI / hev-socks5-tunnel (MIT)

## 1.2.0 — 2026-10-01

- Умный дисковый кэш: prefetch **3** следующих трека, лимит **64–256 МБ** (5% свободного места)
- До ~10 МБ на префетч-трек; при смене трека/плейлиста удаляются ключи вне окна current+3
- Документация: почему Zapret нельзя встроить в APK; как пользоваться внешним DPI-обходом без классического VPN

## 1.1.1 — 2026-10-01

- Исправлено падение при старте: ExoPlayer больше не вызывается с `ConnectivityThread` (сетевой callback → main)

## 1.1.0 — 2026-10-01

- Возобновление потока при потере/смене сети (Wi‑Fi ↔ мобильный интернет): сброс OkHttp-пула, новый URL, seek на ту же позицию
- Сохранение очереди, текущего трека и позиции (DataStore); восстановление после закрытия приложения
- Play/Pause больше не сбрасывает трек на начало
- `ACCESS_NETWORK_STATE` для отслеживания сети

## 1.0.0 — 2026-09-30

- Первый публичный релиз: аудиоплеер YouTube / YouTube Music
- Фон (Media3 MediaSession), поиск, библиотека, cookie-вход
- APK в `releases/`
