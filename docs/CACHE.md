# Кэш и офлайн-воспроизведение

Как YouTube Voice качает аудио на диск и играет без сети.

## Зачем

- **Лимит кэша** (64–512 МБ) — потолок SimpleCache / LRU, не «квота на соседний трек».
- **Окно** — то, что ещё нужно проиграть: от позиции воспроизведения вперёд.
- **URL YouTube** нужен только чтобы докачать сегменты. Играть можно с диска.

## Окно докачки

Якорь — текущая позиция (play или pause).

1. Уже сыгранное почти не качаем; оставляем небольшой back-buffer (~30 с).
2. Качаем остаток **текущего** трека от playhead.
3. Затем **следующие** треки в порядке окна — каждый целиком.
4. Стоп: заполнен лимит МБ **или** кончилось число «треков вперёд» в настройках.
5. Треки «назад» в плейлисте можно держать в окне вытеснения, но бюджет докачки на них не тратится.

При seek prefetch перезапускается с нового `fromGosq`. При смене лимита кэша fill тоже перезапускается сразу (сдвигать трек не нужно).

## Офлайн

| Ситуация | Поведение |
|---|---|
| Есть сегменты на диске | Старт / Play через локальный m3u8 или `ytvcache://` |
| Нет сети, был https/HLS | Fallback на диск с сохранением позиции |
| Неполный офлайн-плейлист | Играем отрывок; в HTTPS **не** апгрейдим без сети |
| Сеть снова есть | В фоне: incomplete offline → stream; снова fill |

Неполный офлайн-плейлист пишется **без** `#EXT-X-ENDLIST`, чтобы ExoPlayer не считал отрывок концом трека и не скипал дальше.

## UI

- **Play / Pause** — только управление плеером. Не спиннер фоновой докачки.
- **Фоновая докачка кэша** — отдельная строка под прогрессом занятого места.
- В настройках у «Макс. размер кэша»: свободно на телефоне и оценка «можно выделить до ~N МБ».

## Ключи и дедуп

Сегменты кэшируются со стабильными ключами (itag + gosq и т.п.). Дубли CDN схлопываются при warm и перед сборкой офлайн-m3u8.

## Связанный код

- `PlaybackService` — prefetch, recover, offline fallback / upgrade
- `OfflinePlayback` — локальный m3u8 / `ytvcache`
- `TrackCacheProgress` — полнота, ahead от позиции (`upcomingComplete`)
- `AudioCacheStore` / `CacheSettingsStore` — диск и настройки
- `StreamUrlStore` — последние URL для fill (LRU)
