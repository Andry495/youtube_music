# Сеть и блокировки (без VPN)

Если YouTube / googlevideo у провайдера режется или сильно замедляется, приложение само по себе это не обходит: оно ходит по обычному HTTPS, как браузер.

## Почему Zapret нельзя «вшить» в приложение

[Zapret](https://github.com/bol-van/zapret) обходит DPI на уровне **пакетов** (подмена/фрагментация TCP, raw sockets, iptables/nftables). Это системный инструмент ОС (ПК / root / отдельный tun), а не библиотека для обычного Android APK.

Обычное приложение видит только свой TLS-сокет и **не может** менять пакеты так, как Zapret на ПК.

## Что делать на телефоне

Используйте **внешний** DPI-обход на устройстве (локальный tun / ByeDPI / сборки Zapret под Android и аналоги). Они поднимают системный «VPN»-профиль **без зарубежного сервера** и пропускают трафик (в т.ч. YouTube Voice) через локальный обход DPI.

1. Установите выбранный DPI-bypass клиент.
2. Включите его и при необходимости добавьте `com.youtubevoice.app` в список приложений / «весь трафик».
3. Откройте YouTube Voice как обычно.

YouTube Voice **не** встраивает VpnService и не копирует движок Zapret. Подробнее по архитектуре кэша и плеера: [ARCHITECTURE.md](ARCHITECTURE.md).
