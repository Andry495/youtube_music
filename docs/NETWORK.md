# Сеть и встроенный обход DPI

DPI в приложении — **опциональный** модуль. По умолчанию выключен: DNS/HTTP идут как у системы, можно слушать через VPN телефона (StrongSwan, WireGuard и т.д.).

Встроенный TUN — отдельный системный VPN. Android держит только один: если включить DPI в приложении, VPN телефона отключается.

## Рекомендуемые режимы

| Цель | Что включить |
|---|---|
| Обход на всём устройстве | VPN телефона, DPI в приложении **выкл.** |
| Только трафик YouTube Voice | DPI в приложении **вкл.** (диалог «Разрешить VPN») |

## Когда DPI включён: локальный TUN

`трафик приложения → Android VpnService (только этот пакет) → hev-socks5-tunnel → ByeDPI → интернет`

- Удалённого VPN-сервера нет
- Исходящие сокеты ByeDPI исключаются из TUN (`--protect-path` / `protect()`)
- OkHttp без SOCKS: desync на уровне пакетов в TUN

## Запасной путь: SOCKS

Если диалог VPN отклонить — локальный ByeDPI SOCKS только для OkHttp (слабее на части провайдеров).

## Автоподбор

Кнопка «Тест и подбор пресета» перебирает встроенные пресеты на устройстве и сохраняет рабочий. На части сетей TSPU пресет может не найтись — тогда внешний VPN/Zapret.

См. также [NOTICE.md](../NOTICE.md).
