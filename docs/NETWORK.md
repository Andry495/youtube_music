# Сеть и локальный DPI

## Встроенный обход DPI (с 1.3.1)

В настройках (шестерёнка) — тумблер **«Обход DPI»**.

- Поднимается локальный **SOCKS5 ByeDPI** на `127.0.0.1:1080`
- OkHttp / плеер / NewPipe ходят через этот прокси
- **Системный VPN не нужен**, удалённого сервера нет
- Только трафик YouTube Voice

Пока тумблер включён, сервис может работать в фоне. Статус в настройках: выкл / подключение / активен / ошибка.

## Почему не VpnService

Полноценный TUN+hev на части устройств не поднимался стабильно (разрешения/петли protect). Для «только наше приложение» SOCKS-режим проще и надёжнее: DPI-desync делает ByeDPI на исходящих соединениях прокси.

## Внешние инструменты

Если пресета мало — внешний ByeDPI / Zapret на всё устройство. См. также [NOTICE.md](../NOTICE.md).
