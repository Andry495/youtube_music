# Сеть и локальный DPI

## Встроенный обход DPI (с 1.3.0)

В настройках приложения (иконка шестерёнки) есть тумблер **«Обход DPI»**.

- Поднимается системный VPN-профиль **без удалённого сервера**
- Через туннель идёт **только** трафик YouTube Voice
- Движок: [ByeDPI](https://github.com/hufrea/byedpi) (SOCKS5) + [hev-socks5-tunnel](https://github.com/heiher/hev-socks5-tunnel)
- Исходящие сокеты ByeDPI исключаются из TUN через `--protect-path` (иначе петля)

Пока тумблер включён, сервис может работать в фоне вместе с плеером. Выключение тумблера или отзыв VPN в системе останавливает обход.

На Android одновременно активен только один VPN-профиль: другой VPN нужно выключить.

## Внешние инструменты

Если встроенного пресета недостаточно, можно использовать внешний ByeDPI / Zapret-сборки на всё устройство — см. ниже.

## Почему нельзя «вшить Zapret как на ПК»

[Zapret](https://github.com/bol-van/zapret) работает на уровне пакетов ОС (`nfqws`, iptables). Обычное приложение без root/VPN не может так же править чужие пакеты. Локальный `VpnService` — практичный Android-аналог для своего трафика.
