# Дисклеймер

## Назначение

**YouTube Voice** — открытый учебный / персональный Android-проект: фоновый аудиоплеер, UI на Jetpack Compose и работа с контентом YouTube через сторонние клиенты (InnerTube / NewPipe Extractor).

Проект **не** замена официальных YouTube / YouTube Music и **не** публикуется в магазинах приложений.

## Статус

- YouTube, YouTube Music, Google и связанные знаки принадлежат их правообладателям.
- Репозиторий не предоставляет коммерческих прав на сервисы YouTube.
- Сборка и использование — на стороне того, кто запускает приложение.
- ПО предоставляется «как есть», без гарантий стабильности.

## Магазины приложений

Публикация в **Google Play**, **RuStore** и аналогах **не планируется**.  
Единственный канал распространения — этот репозиторий GitHub (исходники и готовый APK).

## Товарные знаки

Название «YouTube Voice» описывает назначение приложения для разработчиков и пользователей репозитория.  
Это **не** аффилиация, спонсорство или одобрение со стороны Google / YouTube.

## Техническая оговорка

Протоколы потоков могут измениться в любой момент — воспроизведение может потребовать обновления кода.
